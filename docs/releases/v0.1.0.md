# InkLet 0.1.0（墨点）

第一个公开版本。

InkLet 是一个面向学术写作的 Markdown 编辑器。公式按 LaTeX 写，编辑器里直接显示排好的结果；文件是普通的 `.md`，不进数据库，也不用专有格式；需要打印或发给别人时导出 PDF。

## 这个版本能做什么

**写作**

- 实时渲染：光标离开语法标记就显示成品样式，回到标记上又变回源码
- 两种视图：实时渲染或左右对照，`⌘1` / `⌘2` 切换
- 数学：行内 `$…$`，行间 `$$…$$` 或 `\[…\]`，由 MathJax 渲染成内联 SVG，离线可用；需要编号时在公式里写 `\tag{2.1}`
- 代码块：`⌘⌥C` 选语言，16 种语言高亮，导出 PDF 时保留
- 表格：点单元格直接改，`⌘↵` 加一行
- 注释：`> ` 开头的行渲染成灰色注释块，适合放旁注、推导提示和引用
- 链接：`[文字](网址)` 支持省略 `https://`（如 `example.com`）；`[文字](note.md)` 打开工作区里的文件；按住 `⌘` 点击才跳转，方便先编辑
- 文内跳转：`<id:xxx>` 做锚点，`[文字](#xxx)` 或 `[文字](xxx)` 跳到对应位置；重复的标识符会有黄色波浪线提示
- 大纲按标题跳转，文件树按文件夹管理

**文件**

- 工作区：左边是文件夹树，右边是大纲；把文件夹或 `.md` 拖进窗口即可切换
- 右键菜单：创建副本、复制（真实文件进系统剪贴板，可到 Finder / VS Code 里粘贴）、复制文件路径、重命名、删除
- 从 Finder 复制文件或文件夹，回到窗口按 `⌘V`，确认后递归粘贴到当前文件夹；同名自动编号，不覆盖
- 预览图片和 PDF
- 关闭标签页或退出时提示保存；文件被其他程序改动后，保存会提示冲突

**界面**

- 内置终端：右上角入口，默认进入当前文件夹；`✕` 收起（进程保留）、垃圾桶结束会话、拖动上沿调整高度
- 四套配色：浅色、暖纸、蓝灰、深色
- 正文字号、行距、段间距、页边距、界面缩放都可调
- 中文 / English 界面
- 使用指南在 **文件 → 使用指南**（`⌘⇧H`）

**输出**

- 导出 PDF：渲染成自包含 HTML，调用本机 Chrome 或 Edge 打印，公式、图片、代码高亮都内联进文件
- 链接和文内锚点在导出的 PDF 里同样可以点击

## 下载

- macOS（Apple Silicon）：`InkLet_0.1.0_aarch64.dmg`，打开后把 InkLet 拖进「应用程序」
- Windows（64 位）：`InkLet_0.1.0_x64-setup.exe`

## 安装说明

**macOS 首次打开会被系统拦一下。** 这个版本没有开发者签名，会提示「无法验证开发者」：

- 在「应用程序」里按住 Control 点按 InkLet，选「打开」，再确认一次
- 或执行 `xattr -dr com.apple.quarantine /Applications/InkLet.app`

**Windows** 安装时可能出现 SmartScreen 提示（同样因为没有代码签名），点「更多信息 → 仍要运行」。

## 已知限制

- 只有 Apple Silicon 的 macOS 包和 64 位 Windows 包，没有 Intel Mac 版本
- 导出 PDF 依赖本机安装 Chrome 或 Edge
- 没有文件监视：别的程序改了文件，保存时会提示冲突，需要手动重新载入
- 每个窗口只能打开一个工作区
- 链接只支持 http / https / mailto 与工作区内的文件
- 内置终端使用系统 shell（macOS 为 `$SHELL`，Windows 为 `COMSPEC`），尚未在 Windows 上充分测试

## 校验

文件是本地编译产物，没有附带校验和。如果在意完整性，可以从源码自行构建（见 README「从源码运行」）。
